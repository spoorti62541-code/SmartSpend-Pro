# Smart Expense Tracker (Mini Project)

## Tech Stack
- HTML, CSS, JavaScript
- IndexedDB (client-side database)
- Chart.js (graphs and reports)

## Features
- Add, edit, delete expenses
- Search + filter by date and category
- Monthly estimate warning
- Undo delete
- CSV import and export
- Donut chart for category-wise spending
- Reports page:
  - Monthly bar & line charts
  - Weekly bar chart
  - Category pie chart
  - Month / week filters
  - Color modes: default & rainbow
